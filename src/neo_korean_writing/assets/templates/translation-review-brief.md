# 번역 검토 인계서

실제 작업에 필요한 항목만 채운다. 이 양식은 자동 채점표가 아니다.

- 언어 방향:
- 독자·장르:
- 목적: 이해용 / 내부 배포 / 대외 배포 / 출판
- 초벌의 출처: 사람 / 기계 / 혼합 / 미상
- 목표 품질: 기본 정확성과 이해 가능성 / 배포 가능한 완전 후편집
- 편집 강도: 보수 / 기본 / 적극 (목표 품질과 별개)
- 원문·초벌·수정본 파일:
- 보호 항목: 인명·기관명·수치·단위·인용·코드·실제 토큰
- 용어집: 권장어 / 허용 변형 / 금지어 / 사용 문맥 / 공식 출처
- UI 예시: 실행용 토큰인지 표시용 예시인지, 개발자 설명
- 형식 프로필: auto / plain / html / xml / icu (실제 점검 범위·제외 항목 기록)
- 용어집 적용 조건: domain / segment-id / 미확정 다의어(TERM-4) 확인 결과
- 화자·청자·관계·높임말·인용의 예외:
- 판단에 필요한 이웃 문장·문서·기준일:
- 문체 표본과 위치: 원문 특징 / 번역 선택 / 발주처 규칙 / 미상 (한 문장으로 개인 문체를 확정하지 않음)
- 미해결 표현: 확인 질문 / 목적·위험 / 실제 확인한 출처·범위 / 조사 종료·보류 이유
- 전개·호흡: 정보 공개 순서 / 반복·쉼의 기능 / 변경 효과 (해당 장르에서만)
- 기사일 때: 원 매체·제휴 게재 매체 / 발행·수정·사건 시각과 시간대 / 열람 범위
- 기사 핵심 주장: 화자 / 주장 / 가능성·조건 / 확인·반박·미확인 상태 / 원문 위치
- 수치·조사: 값·단위 / 대상 집단 / 비교 시점 / 전체·하위 표본 / 계산 추가 여부

## 검토 기록

발견한 후보마다 원문 위치, 번역문 위치, 관련 문맥, 문제 설명, 수정안 또는 유지 이유를 적는다. 대안 번역이라는 이유만으로 오류로 확정하지 않는다.

- 차원: 의미 정확도 / 자연스러움 / 용어 / 문체·말투 / 독자·지역 / 구조·마크업
- 상태: 검토 후보 / 확인된 오류 / 허용 / 보류
- 중요도와 근거: 사용 목적에 미치는 영향 (횟수만으로 결정하지 않음)
- 기계적 보존 검사 결과: 실제 오류 심각도와 구별 (위험의 `basis`가 mechanical-check인지 heuristic-candidate인지 함께 적는다)
- 출처·문맥을 확인한 뒤 판단이 달라졌는가:
- 초벌에서 사라진 오류 (`baseline_delta.translationese.fixed`):
- 후편집으로 새로 생긴 오류 (`baseline_delta.translationese.introduced`, EDIT-4):
- 어체·높임말·표면 잠금 변화 (`baseline_delta.register`, `surface_lock`, EDIT-3):
- 숫자·단위 대조: 허용 별칭 정규화인지, 실제 값·단위·횟수 변경인지 (통화·배율 변환은 사람 확인)
- 확인 필요·검토자 결정:

## 마무리

목표 품질 충족 여부와 미해결 항목을 적고, 변경률·자동 검사 결과는 별도로 붙인다. 자동 검사 통과를 번역 전체의 사실성·정확성 인증으로 표현하지 않는다. 문학 원고의 의도된 모호성·반복, 업무 문서의 불확실성·조건·의무 수준은 마지막에 원문과 다시 대조한다.
