## 기록

| 발행일 | 제목(요약) | 유형 | 분량(자) | 도입 유형 | 발행 시각 | 반응 1 | 반응 2 | 반응 3 | 비고 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

반응 1~3의 이름은 채널에 맞게 바꿉니다(좋아요·댓글·공유, 조회·공감·저장 등). 비고에는 사진·영상 유무, 광고 집행, 다른 채널 공유 여부를 적습니다.

## 점검 질문 (10건 이상 쌓인 뒤)

- 유형별 반응 중앙값은 어떻게 다른가
- 도입 유형별 차이가 같은 조건(시각·사진 유무)에서도 유지되는가
- 분량에 따른 차이가 있는가
- 한 편이 크게 벗어난 경우 그 조건은 무엇이었나
