# LOCK 보존 항목 대조표

윤문 전과 후에 바뀌면 안 되는 정보를 기록합니다. 이 표는 AI에게 전달하는 제약 조건이면서, 편집자가 최종 확인하는 검수 기록입니다.

| ID | 유형 | 원문 기준 표기 | 위치 | 출처·확인 담당 | 변경 규칙 | 윤문 후 확인 |
|---|---|---|---|---|---|---|
| L-01 | 수치·단위 |  |  |  | 숫자·단위·부호 유지 |  |
| L-02 | 날짜·기간 |  |  |  | 날짜·시간대·기간 유지 |  |
| L-03 | 고유명사 |  |  |  | 공식 표기 유지 |  |
| L-04 | 직접 인용 |  |  |  | 한 글자도 변경 금지 |  |
| L-05 | 조건·면책 |  |  |  | 누락·완화·강화 금지 |  |
| L-06 | 링크·연락처 |  |  |  | 문자 단위 확인 |  |
| L-07 | 표·목록 |  |  |  | 항목·순서·값 유지 |  |
| L-08 | 코드·명령·파일 경로 |  |  |  | 문자 단위 확인 |  |
| L-09 | YAML·각주·헤딩 |  |  |  | 구조와 값 유지 |  |

## 검수 절차

1. 윤문 전 원고에서 숫자, 날짜, 고유명사, 직접 인용, URL, 표와 목록을 찾습니다.
2. 변경 금지인지, 표기 통일을 허용하는지, 사실 확인 후에만 바꿀 수 있는지 구분합니다.
3. 윤문본에서 같은 위치 또는 대응 문단을 찾아 표의 `윤문 후 확인` 열에 결과를 기록합니다.
4. 누락·변경·불일치가 있으면 즉시 확정하지 말고 `[확인 필요]`로 돌립니다.
5. 원문과 수정본은 함께 보관하고, 가능하면 아래 명령으로 자동 대조를 보조합니다.

```bash
python3 scripts/korean_writing.py preserve 원문.md 윤문본.md --strict
```

> 이 표는 의미 해석을 대신하지 않습니다. 인용의 의도, 법률·의료·재무 문구의 적절성, 고유명사의 공식 표기는 담당자가 최종 확인해야 합니다.
