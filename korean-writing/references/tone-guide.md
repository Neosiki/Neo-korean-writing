# 톤과 구조 선택

구조는 고정 슬롯이 아니라 자료와 목적에 맞춰 선택한다.

- 주장형: 핵심 주장 → 근거 → 반론 또는 조건 → 함의
- 장면형: 제공된 장면 → 문제 → 해석 → 판단
- 데이터형: 수치 → 비교 기준 → 원인 해석 → 제한
- 사례형: 사례 → 작동 원리 → 적용 범위 → 주의점
- 문서형: 범위 → 항목별 설명 → 권고 → 다음 행동

칼럼은 하나의 관점을 세우고, 문서형은 정보 검색성과 책임 주체를 우선한다. 질문형 도입, 반전, 감성 문장은 자료에 근거하고 실제로 글의 역할을 할 때만 쓴다.

마무리는 구체적 권고, 남은 쟁점, 제한 조건, 다음 행동, 함의 중 알맞은 것을 고른다. 매번 요약이나 “관점 재정렬”을 강제하지 않는다.
