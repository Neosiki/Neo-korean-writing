# 문체 프로파일

사용자의 글처럼 쓰려면 "차분하게", "담백하게" 같은 형용사보다 표본에서 확인한 사실이 필요하다. 이 문서는 표본으로 프로파일을 만들고 초안이 거기서 벗어났는지 보는 절차다. 인계 계약에서는 `voice.profile`을 `custom`으로 두고 `voice.sample`에 프로파일 파일 경로를 적는다.

## 만드는 순서

1. 사용자가 직접 쓴 글 세 편 이상을 받는다. 같은 채널·같은 장르면 더 좋다. AI가 쓴 초안이나 남이 고친 글은 표본에서 뺀다.
2. 통계를 뽑는다.

   ```text
   python ../scripts/korean_writing.py voice-profile 표본1.md 표본2.md 표본3.md --json
   ```

3. `../templates/voice-profile.md`를 채운다. 통계 칸은 도구 출력으로, 나머지는 표본에서 찾은 실제 문장을 근거로 적는다.
4. 사용자에게 보여 주고 고칠 곳을 받는다. 프로파일의 주인은 사용자다.

표본이 20문장 미만이면 도구가 `reliable: false`를 낸다. 이때 통계는 참고로만 쓰고 프로파일에 "표본 부족"이라고 적는다.

## 프로파일에 담는 것

| 항목 | 적는 내용 | 근거 |
|---|---|---|
| 종결 | 합니다체·해요체·한다체 비율, 섞어 쓰는 자리 | 통계 `endings` |
| 문장 길이 | 평균·중앙값, 짧은 문장과 긴 문장의 비율 | 통계 `sentence_chars` |
| 장치 | 물음, 괄호, 접속 부사, 1인칭을 쓰는 빈도 | 통계 |
| 어휘 | 자주 쓰는 낱말, 쓰지 않는 낱말 | 표본 문장 인용 |
| 전개 습관 | 사례를 먼저 쓰는지, 판단을 먼저 쓰는지 | 표본 문단 |
| 핵심 규칙 | 이 사람 글에서 지켜지는 규칙 3~5개 | 규칙마다 표본 예문 한 쌍 |
| 이탈 징후 | 이것이 보이면 이 사람 글이 아닌 신호 | 표본에 한 번도 없는 것 |
| 금지 어휘 | 사용자가 쓰지 말라고 한 말 | 사용자 지시 |

핵심 규칙과 이탈 징후는 사용자가 확인한 것만 남긴다. 표본 세 편에서 본 경향을 그 사람의 원칙으로 단정하지 않는다.

## 초안 대조

```text
python ../scripts/korean_writing.py voice-profile 표본1.md 표본2.md --compare 초안.md --json
```

| 결과 | 뜻 | 처리 |
|---|---|---|
| `aligned` | 측정한 축에서 큰 차이가 없음 | 어휘·전개는 사람이 읽고 확인 |
| `drift` | 종결·길이·리듬·장치·인칭 중 차이가 있음 | 해당 축만 고친다. 사실·LOCK은 그대로 |
| `insufficient_sample` | 표본이 부족해 판정 범위 밖 | 통계 없이 표본을 직접 읽고 맞춘다 |

`person` 축은 따로 본다. 표본에 1인칭이 없는데 초안에 생겼다면 자료에 없는 경험을 지어냈을 수 있다. 근거가 없으면 지운다.

도구는 문체가 "같다"고 판정하지 않는다. 통계가 비슷해도 어휘와 전개가 다르면 다른 글로 읽힌다. 직접 인용·코드·제목은 통계에서 빠진다.

## 적용 범위

- 프로파일은 문장의 소리를 정한다. 없던 1인칭·감정·일화·수치를 만들 권한이 아니다.
- 채널 형식이 프로파일과 부딪히면 형식(글자 수·평문)을 먼저 지키고 그 안에서 문체를 맞춘다.
- 윤문에서는 원문의 문체가 프로파일보다 우선한다. 프로파일은 새 글과 "내 문체로 고쳐줘" 요청에 쓴다.
- `yoon-reporter`는 저장소에 든 프로파일 예시다. 같은 형식으로 자기 프로파일을 만들면 된다.
