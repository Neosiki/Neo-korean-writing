# 장문 작성과 검증

8,000자 이상은 마스터 아웃라인, 용어집, 주장·출처 지도, 섹션별 목적을 먼저 만든다. 실제 청킹은 15,000자 초과 또는 사용자가 요청한 경우에만 헤딩·문단·문장 경계에서 수행한다.

각 섹션은 독립적으로 완결시키되 앞 절의 결론을 반복해 분량을 늘리지 않는다. 통합 후 용어, 주체, 시간축, 수치, 인용, 결론 강도를 대조한다. 청크 재조립 결과가 원문과 한 글자라도 다르면 윤문을 중단한다.

장문에서도 고정된 도입·전환·기준·마무리 슬롯을 모든 절에 반복하지 않는다. 절의 역할에 따라 주장형·데이터형·사례형 구조를 섞는다.
