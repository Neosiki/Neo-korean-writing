# 단계별 산출물

- 목적 정의: context와 한 문장 목적
- 구조 설계: 선택한 구조와 각 부분의 역할
- 초안: 출처가 있는 주장과 `[확인 필요]`를 구분한 본문
- 리라이팅: 수정본, 실제 변경, 보류 항목
- 최종 출력: 채널 포맷을 적용한 본문과 필요한 검증 상태

초안에서 윤문으로 넘어갈 때 `../templates/writer-editor-handoff.json` 형식으로 작성 의도·출처·LOCK·변경 예산을 전달한다. 파일을 요청하지 않은 대화형 작업에서는 같은 항목을 내부 체크리스트로 유지하고 불필요한 작업 파일을 만들지 않는다.
