# 발행 포맷

채널 요구가 있을 때만 형식을 바꾼다.

- 페이스북·카카오톡 평문: Markdown 표지 없이 짧은 단락으로 쓴다. 첫 두 줄은 내용을 대표해야 하지만 과장형 후크를 만들지 않는다.
- 블로그: 검색과 탐색에 도움이 되는 구체적 소제목을 사용한다.
- 보고서·기술문서: 목록·표·코드를 정보 구조에 맞게 보존한다.
- 보도자료: 제목, 리드, 본문, 문의처의 기능을 구분한다.

제목 후보, 해시태그, CTA, SNS 요약은 사용자가 요구하거나 채널 계약에 포함됐을 때만 만든다.

채널별 첫 화면·분량·서식 기준과 발행 전 검사는 [채널 플레이북](channel-playbooks.md)에 있다. 이 문서는 채널이 정해지지 않았을 때의 최소 기준이다.
