# 외부 글쓰기 스킬 대조 기록 (2026-11-10)

v10.9의 새 글 작성 보강은 공개 저장소 `methylo/claude-skill-book` v1.0(커밋 `a2351b5`, 2026-11-10 확인, CC BY-NC 4.0)과 대조해 설계했다. 이 문서는 무엇을 참고했고 무엇을 받아들이지 않았는지 남긴다.

## 대조 범위

- 상대: 글쓰기 스킬 7개(범용·블로그·네이버 정보글·페이스북·페이스북 에세이·브런치·에세이)와 책 퇴고·독자 피드백 스킬의 SKILL.md와 참조 파일
- 이쪽: v10.8의 `korean-writing/` 작성 경로와 루트 윤문 경로

읽고 비교한 기록이다. 두 스킬로 같은 글을 써서 품질을 견준 실험이 아니다.

## 구조 차이

| 항목 | 상대 | v10.8 |
|---|---|---|
| 구성 | 채널·장르마다 독립 스킬 | 작성 경로 하나 + 윤문·번역 경로 |
| 작성 참조 분량 | 글쓰기 7개 스킬에 약 300KB | 참조 7개에 약 5KB |
| 구조 | 유형별 슬롯을 순서대로 채움 | 자료에 맞춰 선택, 슬롯 누출은 P0 |
| 금지어 | 목록 전체를 일괄 금지 | 실측으로 승격·강등, 유지 조건 우선 |
| 검증 | 체크리스트 자가 점검 | 결정적 스크립트, 게이트, 회귀 테스트 |
| 문체 | 저자 문체 파일을 교체해 쓰는 구조 | `preserve` 기본, 선택형 voice |
| 발행 뒤 | 성과 기록표로 스킬 조정 | 없음 |

## 받아들인 생각

문장을 옮기지 않고 구조만 참고해 이 저장소의 원칙에 맞게 새로 썼다.

| 생각 | v10.9 반영 | 바꾼 점 |
|---|---|---|
| 유형별 기본 분량 | `content-types.md` | 합격선이 아닌 출발점으로 둠 |
| 요청 동사로 보존 강도 판별 | `content-types.md`의 변경 권한 표 | 기존 강도(보수·기본·적극)와 인계 계약에 연결 |
| 채널별 설계 | `channel-playbooks.md`, `channel-check` | 수치마다 근거 등급을 붙이고 플랫폼 한도만 차단 |
| 도입 유형과 실패 유형 | `opening-closing.md`, CH-9 | 자료에 있는 재료로만, 유지 조건 병기 |
| 문체 파일의 핵심 규칙·이탈 징후 | `voice-profile.md`, `voice-profile` 명령 | 표본 통계와 사용자 확인을 근거로 삼음 |
| 스킬 간 변환 표 | `repurposing.md` | 줄이는 변환의 누락·단정 변화 기록 추가 |
| 에세이의 시선 설계 | `essay-gaze.md` | 재료 확인 질문을 앞에 두고 경험을 만들지 않게 함 |
| 발행 성과 기록 | `performance-log.md`, 템플릿 | 에이전트가 수치를 채우지 않음, 조정 문턱 명시 |

스레드와 인스타그램은 상대 저장소에 없다. 이 저장소의 사용 채널에 맞춰 추가했다.

## 받아들이지 않은 것

| 상대의 규칙 | 이유 |
|---|---|
| "~할 수 있습니다"를 단정형으로 전환 | 가능성·추정을 사실로 바꾸면 의미가 달라진다. 철칙 1(의미 불변)과 충돌 |
| "따라서", "결과적으로" 등 연결어 금지 | 실제 인과·반전 표지는 보존한다. 반복될 때만 후보 |
| 과장 형용사·부사 목록 일괄 금지 | 근거 없이 판단을 대신할 때만 고친다. 직접 인용·필자 말투는 유지 |
| 슬롯 순서 강제, 마무리를 관점 전환으로 고정 | 모든 글이 같은 골격이 된다. `structure`가 S-2·S-3로 잡는 대상 |
| 플랫폼 반응 시간·판단 시간 수치 | 출처와 기준일이 없다. 확인되지 않은 수치를 사실로 쓰지 않는다 |
| 문장당 단어 수 기준 | 실측에서는 긴 문장이 없는 쪽이 문제였다(E-1 재정의) |
| 단계마다 사용자 확인 | 결과를 바꾸는 항목이 불명확할 때만 묻는다 |
| 가상 독자 여러 명의 반응 시뮬레이션 | 모델이 만든 반응을 독자 증거처럼 쓰게 될 위험. Editorial Audit의 이탈 지점 진단과 실제 독자 질문 기록을 유지 |

## 확인한 플랫폼 수치

`channel_specs.json`에서 `platform` 등급으로 둔 값의 확인 경로다(2026-11-10 웹 검색).

| 값 | 확인 |
|---|---|
| 스레드 포스트 500자, 텍스트 첨부 10,000자 | Meta 뉴스룸 2025년 9월 공지와 다수 보도 |
| 인스타그램 캡션 2,200자, 해시태그 30개 | 다수 2차 출처 일치. 공식 문서는 직접 확인하지 못함 |

인스타그램 접힘 약 125자는 2차 출처의 보고값이라 `reported`로 두었다. 페이스북 접힘 위치, 네이버·브런치 제목 길이, 문단 길이는 확인된 한도가 없어 `assumption`이다. 브런치 제목 상한은 검색으로 확인하지 못했다.

## 한계

- 새 참조 문서의 효과는 검증하지 않았다. 문서를 추가했다는 사실이 글이 나아졌다는 증거는 아니다.
- `channel-check`는 형식만 본다. 내용의 정확성, 반응, 노출과 무관하다.
- `voice-profile`의 문턱(종결 비율 0.25, 길이 비 0.7~1.4 등)은 보정 전 휴리스틱이다. 로드맵 1의 말뭉치 보정 대상에 포함한다.
- 가정값은 사용자의 성과 기록으로 조정해야 의미가 생긴다.
