## 구간 영향과 원고 보존

bank의 역어만 변경하는 4구간 예문에서 첫 구간과 바로 다음 문맥 구간만 재검토 대상으로 뽑고 나머지 두 구간은 유지한다. 번역 파일 바이트가 그대로인지 대조한다. 상세 회귀는 새 용어·삭제 용어·미사용 용어·분야 미정·의존성 전이·재정렬·번역 누락·한 파일의 문단 지정·기준 기록 덮어쓰기 거부를 포함한다.

## 독자 질문의 실제 응답 예시

`october-reader-records.json`에는 현재 대화 모델이 직접 읽고 답한 자체 예문 5개를 보관했다. 명확한 주체·승인 조건, 모호한 대명사, 빠진 조건, 문서 범위 밖 질문, 표의 조건을 다룬다. 같은 세션이 예문·질문·응답을 모두 작성했으므로 `author_context / independent=false`다. 새로운 독립 독자에게 질문을 숨겨 평가한 결과가 아니다.

`benchmark_october_upgrade.py`는 이 보고서의 해시·근거·질문 범위·상태를 다시 검사한다. 모델을 재호출하지 않는다. 근거 구절이 존재하는지 검증하는 것은 답의 논리적 정확성을 자동 판정하는 일이 아니다. 정답률을 산출하지 않는다. 회귀 테스트의 가짜 이름·fresh 선언 예시는 스키마 동작 시험일 뿐 실제 사람 평가 기록이 아니다.

```text
python scripts/benchmark_october_upgrade.py
python -m unittest discover -s tests
python scripts/validate_repo.py
```

최신 실행 결과는 `october-upgrade-results.json`에 저장한다. 기존 2차 기계 벤치마크와 의미 재검토 기록도 함께 재생해 회귀 여부를 확인한다. 지침·엔진 미러·템플릿·Codex/Claude 패키지는 같은 소스에서 빌드한다.
